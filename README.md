# Журнал группы колледжа

Курсовая работа по теме "Журнал группы колледжа"

## Функционал
- Авторизация (Админ, Староста - персональный вход для каждого)
- Управление студентами (Разделенные права доступа)
- Управление группами( Разделенные права доступа )
- Портфолио студента с характеристикой ( Вывод в PDF )
- Пасхалка с Хаски
